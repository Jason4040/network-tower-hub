# Network Tower Hub

Build a complete, production-quality personal portfolio website for **Irumva Jason**, a third-year IT student specializing in **Networking and Communication Systems** and an **aspiring Cloud Security Engineer**.

The website must feel like a serious technical portfolio for someone pursuing networking, infrastructure, cybersecurity, and cloud security.

Do not make it look like a generic developer portfolio.

The main visual concept is a **3D networking tower / communications infrastructure tower** that acts as the central visual identity and navigation system of the website.

The final result should feel:

* Technical
* Futuristic but professional
* Sophisticated
* Minimal
* Cyber/infrastructure inspired
* Interactive
* High-end
* Easy to navigate
* Visually memorable
* Suitable for recruiters and technical professionals

Do NOT make it childish, overly futuristic, gaming-like, or filled with unnecessary effects.
